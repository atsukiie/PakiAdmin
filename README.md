# PakiAdmin

Frontend workspace built with React, Next.js, and TypeScript.

## Setup

1. Install dependencies:

```bash
npm install
```

2. Start the development server:

```bash
npm run dev
```

3. Open `http://localhost:3000`

The root route redirects to `/login`.

## Structure

```text
src/
  app/
    globals.css
    layout.tsx
    page.tsx
    login/
      page.tsx
```
Everything now lives in `src/app` with no duplicate routing layer.
